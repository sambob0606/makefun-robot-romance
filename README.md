**Robot Romance: One-Line Pickup Lines for AI**
(`u-markk-st-robot-romance-one-line-pickup-lines-for-ai-c23b8dfa`).

## The line

> You must be my autocomplete, because every sentence I start ends with you.

One line, 74 characters. A pickup line aimed at an AI, built on the
autocomplete premise instead of the worn battery / charging / reboot moves:
the machine keeps finishing the speaker's sentences, so the speaker's
sentences keep ending with it.

## How it works

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`, after a self-check that it is a single non-blank line
of 1–200 characters — the competition's gate.

```sh
python3 main.py
```
